Visualisatie startpagina

Gebruik deze pagina als ingang voor de twee actieve visualisaties.

Actieve pagina's

  • Index schema
  • Tijdlijn schema

Requirements

  • JavaScript moet aanstaan in de browser.
  • Internettoegang nodig: React wordt via CDN geladen (unpkg).
  • Moderne browser (Chrome, Edge, Safari, Firefox).
  • Toegang tot API-server op poort 8080 vanaf je netwerk.

Mobiel troubleshooting

  • Test eerst of deze pagina zelf opent: /viz/.
  • Open daarna index_schema.html.
  • Als die leeg blijft: controleer of je telefoon toegang heeft tot unpkg CDN.
  • Probeer tijdelijk wifi en mobiele data om DNS/firewall issues uit te sluiten.

Tip: als React-CDN op mobiel vaak blokkeert, kun je later React lokaal meeleveren in de image.
