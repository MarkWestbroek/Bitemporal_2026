API-gateway Koppeling · roadmap

Een snelle, declaratieve gateway ervoor

KrakenD is een open-source, stateless API-gateway in Go met declaratieve configuratie. Geplaatst vóór de uit het model gegenereerde REST/OpenAPI-endpoints aggregeert, transformeert en beveiligt het de toegang — zonder code, puur configuratie.

Waarom koppelen

Configuratie in plaats van code

KrakenD's declaratieve aanpak sluit aan op Omnium's filosofie: de OpenAPI 3.1 die uit het model komt, kan de gateway-configuratie voeden.

🧬 Aggregatie

Bundel meerdere register-endpoints tot één response, afgestemd op de behoefte van de consumer.

🛡️ Beveiliging

Authenticatie, rate-limiting en quota op de rand — vóór de registers.

⚡ Stateless & snel

Lichtgewicht Go-gateway, eenvoudig horizontaal te schalen.

📝 Spec-gedreven

De gegenereerde OpenAPI 3.1 kan dienen als basis voor de KrakenD-configuratie.

Wat stroomt er

De koppelvlakken

  • Omnium → KrakenD: REST/OpenAPI-endpoints + spec als configuratiebron.
  • KrakenD → consumers: een gestabiliseerde, beveiligde publieke API.
  • Bitemporeel blijft beschikbaar via doorgegeven tijd-query-parameters.
