Visualisatie startpagina

Gebruik deze pagina als ingang voor de twee actieve React + Vite visualisaties.

Actieve pagina's

  • Index (React + Vite)
  • Tijdlijn (React + Vite)
  • Registraties replay (React + Vite)
  • Test coverage rapport (HTML)

Requirements

  • JavaScript moet aanstaan in de browser.
  • Moderne browser (Chrome, Edge, Safari, Firefox).
  • Toegang tot API-server op poort 8080 vanaf je netwerk.

Mobiel troubleshooting

  • Test eerst of deze pagina zelf opent: /viz/.
  • Open daarna /viz/react/.
  • Open de tijdlijn via /viz/react/tijdlijn.html.
  • Open replay via /viz/react/registraties.html.
  • Open coverage via /viz/coverage.html (na run van coverage-task).
  • Probeer tijdelijk wifi en mobiele data om DNS/firewall issues uit te sluiten.

Tip: als assets niet laden, force-refresh de pagina en controleer of de laatste frontend-build is uitgerold.
