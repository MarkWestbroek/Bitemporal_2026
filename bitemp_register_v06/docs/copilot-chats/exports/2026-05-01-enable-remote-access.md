## 🤖 Assistant

De nieuwe "remote" feature in Visual Studio Code 1.118 (mei 2026) maakt het eenvoudiger om direct te werken op externe machines, containers of cloud-omgevingen zonder extra extensies te installeren. Hier zijn de belangrijkste punten:

### Wat is er nieuw?
- **Ingebouwde remote functionaliteit**: Je hoeft geen aparte "Remote - SSH", "Remote - Containers" of "Remote - WSL" extensies meer te installeren; deze zijn nu standaard geïntegreerd.
- **Snellere verbinding**: De connectie met remote hosts is sneller en stabieler, met verbeterde foutafhandeling.
- **Unified Remote Explorer**: Eén centrale plek in de zijbalk om al je remote targets (SSH, containers, cloud workspaces) te beheren.
- **Verbeterde UI**: Je ziet duidelijk of je lokaal of remote werkt, en kunt eenvoudig wisselen tussen omgevingen.

### Hoe gebruik je het?
1. **Open de Remote Explorer**: Klik op het "Remote" icoon in de zijbalk.
2. **Voeg een remote toe**: Kies bijvoorbeeld "SSH Targets", "Containers" of "Cloud Workspaces" en voeg een nieuwe verbinding toe.
3. **Verbind**: Klik op een target om te verbinden. VS Code opent een nieuwe window in de remote context.
4. **Werk direct**: Je kunt nu bestanden openen, bewerken, terminals
